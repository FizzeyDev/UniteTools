How to use the Tier List

🖱️

Add Pokémon / items

Drag a Pokémon, item or battle item from the gallery into a tier row (or click it to add to the first tier). Dragging a Pokémon opens a popup to configure its Move Combo, Unite Move and Passive — toggle the Ask Moves button next to Clear off to skip that popup and place Pokémon instantly with default moves.

↔️

Reorder & remove

Drag items between tiers to move them, or onto the trash zone to remove. Double-click a placed Pokémon to edit its moves again.

✏️

Edit tiers

Click a tier's label to rename it or change its color, duplicate it, or delete it.

📋

Multiple tierlists

Use + Add Tierlist to create a new tab, or duplicate an existing one. Everything auto-saves in your browser.

💾

Import / Export

Export your tierlist(s) as a JSON file to back them up or share them, Import to load them back, or Copy as Text to paste a formatted summary anywhere.

⌨️

Keyboard shortcuts

F Search  ·  P/I/B Pokémon/Items/Battle Items  ·  CtrlM New tierlist  ·  CtrlShiftA New tier  ·  CtrlShiftE Export current  ·  CtrlDel Clear current  ·  ?/H Help  ·  Esc Close
