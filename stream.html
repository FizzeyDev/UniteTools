⚙️ How to Setup

×
1

Choisir une team (onglet Fearless)

Avant de sélectionner un Pokémon, clique sur 🟣 Violette ou 🟠 Orange pour assigner les picks à la bonne équipe. Si aucune team n'est sélectionnée, le Pokémon sera ajouté sans contour coloré.

2

Sélectionner les Pokémon

Clique sur les cartes Pokémon dans la liste de droite. Ils apparaissent dans le panneau gauche avec le contour de la team active. Clique à nouveau sur un Pokémon pour le retirer.

3

Onglet Bans

Passe dans l'onglet ⛔ Bans et choisis quelle team ban en premier (🟣 Violet first ou 🟠 Orange first). Clique ensuite sur les Pokémon à bannir — l'alternance se fait automatiquement (V→O→V→O→V→O). Les bans apparaissent dans le panneau gauche et sur l'overlay dédiée.

4

Choisir la map

Sélectionne la map du match en bas du panneau gauche : Rayquaza, Groudon ou Kyogre. La map sélectionnée s'affiche automatiquement dans l'Overlay Map dédiée, indépendamment des picks et des bans.

5

Configurer dans OBS — 4 sources Browser

Tu dois créer quatre sources Navigateur (Browser Source) dans OBS :

  • Controller — la fenêtre de contrôle principale (à garder ouverte mais hors stream) :
    https://unite-tools.com/stream.html
  • Overlay Picks — affiche les Pokémon sélectionnés par chaque team :
    https://unite-tools.com/stream.html?overlay=true
  • Overlay Bans — affiche les 6 bans (3 par team) :
    https://unite-tools.com/stream.html?overlay=bans
  • Overlay Map — affiche uniquement la map sélectionnée, idéal pour la placer séparément sur la scène OBS :
    https://unite-tools.com/stream.html?overlay=maps
6

Dimensions recommandées pour chaque source

• Controller : ~460 × 700 px (pas dans le stream)
• Overlay Picks : ~750 × 220 px
• Overlay Bans : ~580 × 180 px
• Overlay Map : ~380 × 120 px

7

Activer le fond transparent dans OBS

Pour chaque Browser Source, coche l'option "Supprimer la couleur d'arrière-plan" (ou Custom CSS : body { background-color: rgba(0,0,0,0) !important; }) afin que les overlays s'intègrent proprement par-dessus ta scène de stream.

💡 Astuce : Les boutons 📺 PICKS OBS, ⛔ BANS OBS et 🗺️ MAP OBS ouvrent directement la fenêtre overlay dans les bonnes dimensions. Le bouton ✕ VIDER réinitialise tout (picks, bans et map).
1

Pick a team (Fearless tab)

Before selecting a Pokémon, click 🟣 Purple or 🟠 Orange to assign picks to the right team. If no team is selected, the Pokémon will be added without a colored border.

2

Select Pokémon

Click on Pokémon cards in the right list. They appear in the left panel with the active team's border color. Click again to remove them.

3

Bans tab

Switch to the ⛔ Bans tab and choose which team bans first (🟣 Purple first or 🟠 Orange first). Click Pokémon to ban them — alternation is automatic (P→O→P→O→P→O). Bans appear in the left panel and on the dedicated overlay.

4

Select the map

Choose the match map at the bottom of the left panel: Rayquaza, Groudon or Kyogre. The selected map is shown in its own dedicated Map Overlay, independently from picks and bans.

5

Setup in OBS — 4 Browser Sources

You need to create four Browser Sources in OBS:

  • Controller — the main control window (keep open, but off-stream):
    https://unite-tools.com/stream.html
  • Picks Overlay — shows each team's selected Pokémon:
    https://unite-tools.com/stream.html?overlay=true
  • Bans Overlay — shows all 6 bans (3 per team):
    https://unite-tools.com/stream.html?overlay=bans
  • Map Overlay — shows only the selected map, great for placing it anywhere on your OBS scene independently:
    https://unite-tools.com/stream.html?overlay=maps
6

Recommended dimensions per source

• Controller: ~460 × 700 px (not in stream)
• Picks Overlay: ~750 × 220 px
• Bans Overlay: ~580 × 180 px
• Map Overlay: ~380 × 120 px

7

Enable transparent background in OBS

For each Browser Source, check "Remove background color" (or add Custom CSS: body { background-color: rgba(0,0,0,0) !important; }) so the overlays blend cleanly over your stream scene.

💡 Tip: The 📺 PICKS OBS, ⛔ BANS OBS and 🗺️ MAP OBS buttons open each overlay window at the right size. The ✕ CLEAR button resets everything (picks, bans and map).
