⚙️ How to Setup

×
1

Choisir une team (onglet Fearless)

Avant de sélectionner un Pokémon, clique sur 🟣 Violette ou 🟠 Orange pour assigner les picks à la bonne équipe.

2

Sélectionner les Pokémon

Clique sur les cartes Pokémon dans la liste de droite. Ils apparaissent dans le panneau gauche. Clique à nouveau pour retirer.

3

Onglet Bans

Passe dans l'onglet ⛔ Bans et choisis quelle team ban en premier. L'alternance se fait automatiquement (V→O→V→O→V→O).

4

Choisir la map

Sélectionne la map du match en bas du panneau gauche : Rayquaza, Groudon ou Kyogre. Elle s'affiche dans l'Overlay Map dédiée.

5

Configurer dans OBS — 4 sources Browser

Tu dois créer quatre sources Navigateur (Browser Source) dans OBS :

  • Controller — la fenêtre de contrôle principale :
    https://unite-tools.com/stream.html
  • Overlay Picks — affiche les Pokémon sélectionnés :
    https://unite-tools.com/stream.html?overlay=true
  • Overlay Bans — affiche les 6 bans :
    https://unite-tools.com/stream.html?overlay=bans
  • Overlay Map — affiche uniquement la map sélectionnée :
    https://unite-tools.com/stream.html?overlay=maps
6

Dimensions recommandées

• Controller : ~460 × 700 px
• Overlay Picks : ~750 × 220 px
• Overlay Bans : ~580 × 180 px
• Overlay Map : ~380 × 120 px

7

Activer le fond transparent dans OBS

Pour chaque Browser Source, coche "Supprimer la couleur d'arrière-plan" afin que les overlays s'intègrent proprement.

💡 Astuce : Les boutons 📺 PICKS OBS, ⛔ BANS OBS et 🗺️ MAP OBS ouvrent directement la fenêtre overlay. Le bouton ✕ VIDER réinitialise tout.
