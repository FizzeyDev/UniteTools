⚙️ How to Setup

×
1

Choisir une team (onglet Fearless)

Avant de sélectionner un Pokémon, clique sur 🟣 Violette ou 🟠 Orange pour assigner les picks à la bonne équipe. Tu peux aussi modifier la couleur d'un pick en cliquant dessus dans le panneau gauche.

2

Sélectionner les Pokémon

Clique sur les cartes Pokémon dans la liste de droite. Ils apparaissent dans le panneau gauche. Clique à nouveau pour retirer. Tu peux réorganiser les picks par drag & drop.

3

Onglet Bans

Dans l'onglet ⛔ Bans, choisis l'ordre des bans : Violet en premier (V-O-V-O-V-O), Orange en premier (O-V-O-V-O-V), ou Libre (3 Violet puis 3 Orange automatiquement). Clique ensuite sur les Pokémon à bannir — la couleur est assignée automatiquement. Utilise la carte "+ Ban vide" pour ajouter un ban sans afficher de Pokémon.

4

Choisir la map

Sélectionne la map du match en bas du panneau gauche : Rayquaza, Groudon ou Kyogre.

5

Configurer dans OBS — 4 sources Browser

Tu dois créer quatre sources Navigateur (Browser Source) dans OBS :

  • Controller :
    https://unite-tools.com/stream.html
  • Overlay Picks :
    https://unite-tools.com/stream.html?overlay=true
  • Overlay Bans :
    https://unite-tools.com/stream.html?overlay=bans
  • Overlay Map :
    https://unite-tools.com/stream.html?overlay=maps
6

Dimensions recommandées

• Controller : ~460 × 700 px
• Overlay Picks : ~750 × 220 px
• Overlay Bans : ~580 × 180 px
• Overlay Map : ~380 × 120 px

7

Activer le fond transparent dans OBS

Pour chaque Browser Source, coche "Supprimer la couleur d'arrière-plan" afin que les overlays s'intègrent proprement.
