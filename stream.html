⚙️ How to Setup

×
1

Choisir une team (onglet Fearless)

Avant de sélectionner un Pokémon, clique sur 🟠 Orange ou 🟣 Violette pour assigner les picks à la bonne équipe. Si aucune team n'est sélectionnée, le Pokémon sera ajouté sans contour coloré.

2

Sélectionner les Pokémon

Clique sur les cartes Pokémon dans la liste de droite. Ils apparaissent dans le panneau gauche avec le contour de la team active. Clique à nouveau sur un Pokémon pour le retirer.

3

Onglet Bans

Passe dans l'onglet ⛔ Bans et choisis quelle team ban en premier (🟣 Violet first ou 🟠 Orange first). Clique ensuite sur les Pokémon à bannir — l'alternance se fait automatiquement (V→O→V→O→V→O). Les bans apparaissent dans le panneau gauche et sur l'overlay dédiée.

4

Choisir la map

Sélectionne la map du match en bas du panneau gauche : Rayquaza, Groudon ou Kyogre.

5

Configurer dans OBS (3 sources)

Tu dois créer trois sources Navigateur :

  • Controller → https://unite-tools.com/stream.html
  • Overlay Picks → https://unite-tools.com/stream.html?overlay=true
  • Overlay Bans → https://unite-tools.com/stream.html?overlay=bans
6

Dimensions recommandées

• Controller : largeur ~460px, hauteur ~700px
• Overlay Picks : largeur ~750px, hauteur ~220px
• Overlay Bans : largeur ~580px, hauteur ~180px

💡 Astuce : Les deux overlays se mettent à jour automatiquement (~500ms). Le bouton ✕ VIDER réinitialise picks ET bans. Pour vider uniquement les bans, clique sur le × de chaque slot ou utilise le bouton dans l'onglet Bans (à venir).
1

Pick a team (Fearless tab)

Before selecting a Pokémon, click 🟠 Orange or 🟣 Purple to assign picks to the right team. If no team is selected, the Pokémon will be added without a colored border.

2

Select Pokémon

Click on Pokémon cards in the right list. They appear in the left panel with the active team's border color. Click again to remove them.

3

Bans tab

Switch to the ⛔ Bans tab and choose which team bans first (🟣 Purple first or 🟠 Orange first). Click Pokémon to ban them — alternation is automatic (P→O→P→O→P→O). Bans appear in the left panel and on the dedicated overlay.

4

Select the map

Choose the match map at the bottom of the left panel: Rayquaza, Groudon or Kyogre.

5

Setup in OBS (3 Browser Sources)

You need to create three Browser Sources:

  • Controller → https://unite-tools.com/stream.html
  • Picks Overlay → https://unite-tools.com/stream.html?overlay=true
  • Bans Overlay → https://unite-tools.com/stream.html?overlay=bans
6

Recommended size

• Controller: width ~460px, height ~700px
• Picks Overlay: width ~750px, height ~220px
• Bans Overlay: width ~580px, height ~180px

💡 Tip: Both overlays update automatically (~500ms). The ✕ CLEAR button resets picks AND bans. To clear only bans, click the × on each slot.
