📖 How to Use — XP Calculator
1
Choose your Pokémon and set your starting level.
2
Set the Start Timer (when you start farming) and the Duration of your session.
3
Add kills from the Wild Pokémon grid. Click a Pokémon, set the timer and number of allies sharing XP, then confirm.
4
Add Scoring events using the scoring quick-add row (timer + points scored).
5
Press Classic for an instant summary, or Advanced to watch a real-time simulation that you can speed up to x4.
💡
The XP Table at the bottom shows how much XP each wild Pokémon gives at every timer tick — use it to plan kills efficiently.
